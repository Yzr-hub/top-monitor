# TopMonitor 传感器兼容性

## 验证状态

当前构建与测试在 Apple Silicon macOS 主机上完成，只验证了 Windows 目标的交叉编译、单元测试和发布产物结构。尚未在任何 Windows CPU、GPU 或主板上进行实机读取，因此下表不会把库的理论支持写成“已测试”。

## 已测试硬件

| 类别 | 已测试型号 | 结果 |
| --- | --- | --- |
| CPU | 无 | 待 Windows 实机验证 |
| GPU | 无 | 待 Windows 实机验证 |
| 主板/EC | 无 | 待 Windows 实机验证 |

## 当前实现的指标

| 指标 | 数据来源 | 当前状态 |
| --- | --- | --- |
| CPU 使用率 | Windows `GetSystemTimes` | 已实现，未实机验证 |
| 内存使用率/已用内存 | Windows `GlobalMemoryStatusEx` | 已实现，未实机验证 |
| 上行/下行网络速率 | .NET 网络接口累计字节差值 | 已实现，未实机验证 |
| CPU 温度 | LibreHardwareMonitor | 已实现传感器发现和缓存，未实机验证 |
| GPU 温度/负载 | LibreHardwareMonitor | 已实现多 GPU 发现和缓存，未实机验证 |

当前未实现或未验证的传感器包括风扇转速、电压、功耗、硬盘温度、主板温度、内存 SPD、FPS 和帧时间。传感器缺失时应显示不可用，不使用虚构或固定值。

## 管理员权限

程序默认不请求管理员权限。Windows 系统指标通常可由普通用户读取。部分 CPU/主板/EC/风扇/电压传感器可能需要底层驱动或管理员权限，具体取决于硬件、固件、安全策略和 LibreHardwareMonitor 的访问方式。

排查时可分别以普通用户和管理员运行进行对比，但管理员运行不能作为默认兼容性承诺。不要关闭 Windows 安全功能来换取指标。

## 驱动与反作弊风险

- 内核驱动、硬件监控驱动和厂商工具可能争用相同设备。
- 企业安全策略、核心隔离、驱动签名策略可能阻止低层访问。
- 部分游戏反作弊系统可能限制 ETW、句柄访问或硬件驱动；当前版本未实现 FPS，也未针对任何反作弊产品认证。
- 不应为了读取传感器绕过反作弊、禁用安全软件或加载来源不明的驱动。

出现冲突时先关闭 TopMonitor，保留日志，并记录 Windows 版本、CPU、GPU、主板、BIOS、显卡驱动和安全软件版本。

## Windows 验收矩阵

正式发布前至少覆盖：

- Intel Core 近三代桌面与移动平台。
- AMD Ryzen 近三代桌面与移动平台。
- NVIDIA、AMD、Intel 独立或集成 GPU。
- 单 GPU、多 GPU、无独立 GPU。
- 普通用户与管理员权限对比。
- 休眠恢复、锁屏、远程桌面和显示器热插拔。
- Windows 11 当前受支持版本，开启核心隔离的环境。

每次实测后在本文件记录具体型号、Windows/驱动版本、可读与不可读传感器、权限要求和异常日志摘要。
