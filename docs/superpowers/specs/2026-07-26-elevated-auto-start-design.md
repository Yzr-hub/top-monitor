# TopMonitor 管理员权限开机启动设计

日期：2026-07-26

## 问题

当前开机启动通过当前用户注册表 `Run` 项实现，TopMonitor 登录后以普通权限启动。目标电脑上的 Intel CPU 温度读取需要管理员权限，因此自动启动时 CPU 温度不可用，而右键“以管理员身份运行”后可以正常读取。

## 方案

使用 Windows 任务计划程序替代注册表启动项：

- 任务名称固定为 `TopMonitor`。
- 触发条件为当前用户登录。
- 以当前用户身份、最高可用权限运行。
- 操作为启动当前发布目录中的 `TopMonitor.exe`。
- 开启开机启动时通过一次 UAC 提权创建或更新任务。
- 关闭开机启动时通过一次 UAC 提权删除任务。
- 创建计划任务前删除旧的注册表 `Run` 项，避免重复启动。
- 检测到旧注册表启动项时，在用户下一次保存“开机启动”设置时自动迁移。

## 安全边界

- 不保存用户密码。
- 不创建 SYSTEM 权限任务。
- 不在用户未开启开机启动时创建任务。
- 任务只在当前用户登录时运行。
- 命令行路径必须正确引用，支持包含空格的安装目录。
- 操作失败时保留明确错误信息，不将失败状态显示为成功。

## 运行行为

- 创建任务时可能出现一次 UAC 确认。
- 后续登录 Windows 时由任务计划程序自动以最高权限启动，不再弹 UAC。
- 手动双击 EXE 的权限行为保持不变。
- 关闭开机启动后，不再由计划任务或旧注册表项启动。

## 验证标准

- 启用后计划任务存在、使用最高权限、当前用户登录触发且路径正确。
- 旧注册表 `Run\TopMonitor` 项被删除。
- 禁用后计划任务和旧注册表项均不存在。
- 重复启用具有幂等性，不创建多个任务。
- 路径包含空格时仍能正确启动。
- 全部自动化测试、Release 构建和 Windows x64 发布通过。
