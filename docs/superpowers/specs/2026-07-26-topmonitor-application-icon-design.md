# TopMonitor 统一应用图标设计

日期：2026-07-26

## 目标

为 TopMonitor 制作一套简洁、易识别且适合 Windows 小尺寸显示的应用图标，并将同一视觉资产统一用于：

- Windows 可执行文件（EXE）
- 主窗口与设置窗口标题栏
- Windows 系统托盘

## 视觉设计

采用已确认的 A 方案“性能曲线”：

- 深蓝黑色圆角方形作为主体背景。
- 图标外围四角保持透明，使轮廓在浅色和深色系统界面中都清晰。
- 中央使用从青色过渡到绿色的上升性能曲线，表达实时监控、性能趋势和健康状态。
- 不使用字母或其他文字，避免在 16×16 像素托盘尺寸下变得模糊。
- 控制线条数量和细节密度，优先保证小尺寸识别度。

## 资产规格

- 保留一份 1024×1024 PNG 高分辨率源文件，便于预览和后续调整。
- 保留一份可编辑的 SVG 矢量源文件，确保缩放和重新导出时边缘清晰。
- 生成一个多尺寸 Windows ICO 文件，至少包含：
  - 16×16
  - 20×20
  - 24×24
  - 32×32
  - 40×40
  - 48×48
  - 64×64
  - 128×128
  - 256×256
- 各尺寸使用透明背景并针对小尺寸保持足够的边距、对比度和线宽。

## 项目接入

- 在 WPF 项目中将 ICO 配置为应用程序图标，使发布后的 `TopMonitor.exe` 自带图标。
- 主窗口和设置窗口引用同一个项目资源。
- 系统托盘改为加载同一个图标资源，替换当前运行时生成的 “TM” 文字图标。
- 图标资源随应用程序集打包，不依赖发布目录中的外部图片文件。

## 性能与兼容性

- 图标在构建时嵌入程序集，运行时只加载一次。
- 不增加持续计时器、后台线程或动态绘制。
- 托盘图标复用已加载资源，避免周期性生成位图和额外 GC 压力。
- 保持现有 Windows x64 发布流程不变。

## 验证标准

- Debug/Release 构建与现有自动化测试全部通过。
- 发布后的 EXE 在资源管理器中显示新图标。
- 主窗口、设置窗口和系统托盘均显示统一图标。
- 16×16、32×32 和 256×256 尺寸不存在明显锯齿、裁切或透明边缘异常。
- 启动、打开设置、隐藏到托盘以及从托盘恢复窗口均正常。

## 不在本次范围内

- 不改变悬浮窗布局、颜色主题或监控指标。
- 不制作动画托盘图标。
- 不根据实时负载动态改变图标颜色。
